# NEXORA

Clean-room foundation for the new NEXORA simulation platform.

## Non-negotiable rule
No technical implementation from the previous Global Holdings game may be copied, reused, ported, adapted, or treated as an architectural baseline.

The previous game may be referenced only for product ideas and desired user-facing functionality.

## Design targets
- Smooth, sustained iPhone performance first.
- 20,000 fully functional assets = minimum acceptance target.
- 100,000 assets = architecture design target.
- Deep enterprise simulation with composable business capabilities.
- Discrete-event / multi-rate simulation.
- Data-oriented hot paths.
- Incremental persistence.
- Dedicated diagnostics / black-box tracing from day one.
- Thermal-aware rendering and workload management.
