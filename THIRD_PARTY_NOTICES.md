# Third-Party Notices

## Airports registry

`WebApp/world-data.js` contains a compact airport registry generated with the `airportsdata` Python package (release 20260902). The package is distributed under the MIT License and aggregates public aviation datasets, including OurAirports. The registry is intended for simulation and discovery, not navigation or flight planning.

OurAirports publishes its airport datasets as public domain data: https://ourairports.com/data/

## Ports registry

The compact ports/stations registry was generated from data distributed with `searoute` 1.6.0, licensed under Apache License 2.0. It is used for game simulation and is not a substitute for official port or maritime navigation data.

## Visual library

The asset photographs included in `WebApp/assets/images` are AI-generated fictional imagery created specifically for this project. They intentionally avoid real corporate marks, model logos, readable branding and watermarks.
