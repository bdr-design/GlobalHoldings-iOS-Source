# اختبارات الغلاف الأصلي N1
هذه أدوات اختبار وليست طبقة تشغيل أو مثبت تحديث. المصدر الوحيد للغلاف الحالي تحت iOS/GlobalHoldings.
يُولّد prepare_native_tests.py مصادر الاختبار من هذا المصدر؛ تجميع اختبارات التخزين يتطلب بيئة Apple وCryptoKit.
تشغيل test_update_bridge.cjs يتطلب مخرجات اختبار Swift المطابق والـWebApp الحالي. لا يُعامل فحص البناء النحوي على Linux بوصفه فحص SDK الآيفون.
سجلات Apple السابقة محفوظة في حزمة N1. أُعيد اختبار عقد الجسر الحالي بـ23 حالة باستخدام payload صادر من نفس بايتات Swift التي اختُبرت سابقًا، ولم تُعَد اختبارات الجهاز أو تجميع Apple في R3.
